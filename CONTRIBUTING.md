# Contributing

Thanks for your interest in the Spatial Storytelling Engine.

## Pull requests are not being accepted at this time

The project has a single author and copyright holder, and keeping it that way — for now — avoids
the legal setup (a contributor licence agreement) that merged outside code would require. This is
deferred complexity, not a closed door: if the project reaches the point where accepting
contributions makes sense, a CLA will be added and this note will change.

## What is welcome

- **Issues** — bug reports, questions, and feature suggestions are all read and appreciated.
- **Forks** — the engine is MIT licensed. Fork it, change it, ship it, build a product on it. You
  do not need permission, and you do not owe anything back.

If you have built something with the engine, an issue saying so is genuinely nice to receive.

## A note on story portability

A story is `story.md` plus plain asset files — readable, zippable, and yours. If you fork the
engine, please keep it that way. Nothing in the licence obliges you to, but data portability is the
point of the project, and stories that can be exported and archived are what make it worth using.
